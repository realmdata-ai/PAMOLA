# Data Provenance and Licensing Register

**Scope:** every data asset in this repository and in the published package, plus the
third-party corpora the maintainers use to verify the library (which are *not* distributed).
**Last reviewed:** 2026-10-26.
**Normative rule for `data/raw/`:** [`data/raw/POLICY.md`](data/raw/POLICY.md).

*This register records what is known about where each asset came from and under which terms
it is used. It is provided for transparency, not as legal advice.*

## Status legend

| Status | Meaning |
|---|---|
| **VERIFIED** | Origin is documented in the repository (generator, passport or licence file) and the terms permit distribution under this repository. |
| **DOCUMENTED, GAP** | Origin is documented but a requirement of `data/raw/POLICY.md` is not met (named in the row). |
| **UNVERIFIED** | No source or licence is recorded. The asset stays in the repository until a maintainer confirms its origin; it must not be relied on for new work in the meantime. |

### Removed on 2026-10-26: `hr_job_resume/HR_JOB_SAMPLE.csv`

The file was described in the dataset readme as "~500 synthetic job postings". It actually held
2,000 rows of Russian-language CV records (104 distinct CVs) in the field layout of a public job
board's CV export — full names with patronymics, dates of birth, personal e-mail addresses on
public mail providers and mobile phone numbers — with no passport and no generator. Its
synthetic origin could not be established, so it violates `POLICY.md` §1–§2 and was removed from
the tree. It remains in the Git history; whether the history must be rewritten is a maintainer
decision. No test or example used the file.

## 5. Third-party corpora used for verification — never distributed

The maintainers compare the library against public reference datasets kept in a private local
research workspace. Per `POLICY.md` §4 these are **never committed**, in whole or in part; scripts
reference them by local path and users obtain them from the upstream source.

| Corpus | Used for | Upstream licence / terms | Attribution |
|---|---|---|---|
| UCI Adult (Census Income) | k-anonymity comparison with other libraries | CC BY 4.0 (UCI Machine Learning Repository) | Becker, B. & Kohavi, R. (1996). Adult. UCI Machine Learning Repository. https://doi.org/10.24432/C5XW20 |
| Synthea synthetic patients (COVID-19 100K) | scale stress test (3.19M encounters), PII de-identification | Apache-2.0 (MITRE Synthea; generated data free to use and share) | Walonoski J. et al. (2018). Synthea. JAMIA 25(3):230–238 |
| Datablist sample CSV files (customers-100000) | performance benchmark | free sample data, redistribution for testing permitted by the publisher | https://www.datablist.com/learn/csv/download-sample-csv-files |
| PKDD'99 Financial ("Berka") `trans.csv` | performance benchmark | released for the PKDD'99 Discovery Challenge for research use; **no passport in the workspace — terms to be recorded** | Berka, P. (1999). Guide to the Financial Data Set. PKDD'99 Discovery Challenge |

Results derived from these corpora (timings, aggregate metrics) may be published with the
attribution above; the data itself may not be redistributed by this project.
